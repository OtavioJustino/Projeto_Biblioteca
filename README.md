# Library Management — Data Structures

## English

Academic project in C for the Data Structures course at FATEC.

### Project structure
- `include/` — public interfaces for abstract data types.
- `src/` — C implementations.
- `tests/` — automated tests.
- `docs/` — technical documentation.

### Requirements
GCC (C11), GNU Make, and Linux/WSL.

### Running tests
```sh
make test
```

To remove generated test files:

```sh
make clean
```
